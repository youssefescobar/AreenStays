# Logo generator

The logo SVGs and `components/areen-logo.tsx` are generated by these scripts.

- `mark.py`: the mark, redrawn by hand from the brand sheet. Edit point coordinates here (left side only; the right side is mirrored).
- `lockup.py`: mark + wordmark. Text is shaped with HarfBuzz and converted to one path per glyph (Tajawal Bold for Arabic, Montserrat Medium for English).
- `totsx.py`: turns the SVGs into the React component.

```bash
pip install fonttools uharfbuzz
# put tajawal-700.ttf and montserrat-500.ttf (Google Fonts) in ./fonts
cd scripts/logo
python3 mark.py > ../../public/brand/areen-mark.svg
python3 lockup.py ./fonts > ../../public/brand/areen-logo.svg
cp ../../public/brand/areen-mark.svg mark.svg && cp ../../public/brand/areen-logo.svg lockup.svg
python3 totsx.py ../../components/areen-logo.tsx && rm mark.svg lockup.svg
```
